# Panduan Download APK Kas Go

Seluruh proses kompilasi APK dilakukan secara otomatis oleh **GitHub Actions**.

## Cara Download APK:
1. Buka repository di GitHub: `https://github.com/arbdevai/kas-go`
2. Klik tab **Actions** di bagian atas halaman.
3. Klik workflow run terbaru (mis. "Android CI (Demo APK)").
4. Scroll ke bagian paling bawah ke bagian **Artifacts**.
5. Klik **`kas-go-demo-debug-apk`** untuk mengunduh file zip yang berisi file APK.
6. Ekstrak zip, lalu transfer dan pasang (install) file `.apk` ke smartphone Android Anda.

> **Catatan:** Pada smartphone Android, aktifkan opsi "Install from unknown sources" (Izinkan pemasangan aplikasi dari sumber tidak dikenal) bila diminta.
