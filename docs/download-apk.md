# Panduan Download APK Kas Go (Versi Produksi Resmi)

Aplikasi Kas Go dikompilasi secara otomatis oleh **GitHub Actions**.

## Cara Download APK Versi Produksi:
1. Buka halaman Releases di GitHub: **[https://github.com/arbdevai/kas-go/releases](https://github.com/arbdevai/kas-go/releases)**
2. Pada rilis **Kas Go v1.0.2**, lihat bagian **Assets**.
3. Klik langsung file **`kas-go-app.apk`** untuk mengunduhnya ke smartphone Android Anda.
4. Pasang (install) file `.apk` di smartphone Anda.

## Catatan Fitur & Keamanan:
- **Tanda Tangan Konsisten (v1+v2+v3)**: Aplikasi menggunakan signature keystore terstandarisasi permanen sehingga update versi berikutnya akan langsung menimpa tanpa perlu menghapus aplikasi lama.
- **Kompilasi Rilis AOT Murni**: Bebas dari banner debug atau perlambatan emulator; performa mulus native.
- **Fitur Lengkap**: Edit Profil, Daftar Akun Google, Pencatatan Kas Masuk/Pengeluaran 3 Admin, Hub Pembayaran QRIS/BCA/Jemput Tunai, dan Transparansi Kas.
